# Text to emotional audio generation

## 🌟 Highlights

* **Purpose:** Convert a simple text into emtional audio.
* **Voice support:** After choosing the speaker name from gemini supported speakers, change into audio-parsing api metadata.
* **Application type:** It is console application, built to run directly in terminal.
* **Format Agnostic:** Export directly to .wav .

## ℹ️ Overview

This text to emotional audio generator is light-weight console application, which is designed to implement the Text-to-Speech (TTS) integration. Whether you are building an audio book, or want to make a speech with emotional multi-speaker voices, this tool is effective for you. This provide a clean and intuitive API to turn your string into high quality audio files.

I built this because the solutions were either too bloated for simple use cases and required complex cloud dependencies. This tool aims to keep you audio generation local, private and lightning-fast.

## 🚀 Usage

*Setup the envoironment variables in your .env file.*

``` bash
CHAPTER_NO=book_chapter_number
GOOGLE_GENAI_API_KEY=your_gemini_api_key
```


*Open the terminal, navigate to **audio_generator** directory, install the dependencies and run the app.*

``` bash
cd scripts/audio-generator
npm install
npm start
```

## ⬇️ Installation

Just clone the application!

``` bash
git clone https://github.com/DanishAjma1/islamopedia-books.git
```

And be sure your system must have node installed above 20x version.
